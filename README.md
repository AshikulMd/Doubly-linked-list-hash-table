# Doubly-linked-list-hash-table
Java implementation of a Doubly Linked List and Hash Table using separate chaining.
# Doubly Linked List and Hash Table in Java

## About the Project
This project implements two fundamental data structures in Java: a Doubly Linked List and a Hash Table. It demonstrates their basic operations and how they manage data.

## Data Structures

### 1. Doubly Linked List
A doubly linked list is a linear data structure where each node stores data and references to both the previous and next nodes.

**Features:**
- Add elements
- Insert elements at a specific index
- Remove elements by index
- Get and update elements
- Search for elements
- Check whether an element exists
- Traverse forward and backward
- Clear the list

### 2. Hash Table
A hash table stores key-value pairs and uses a hash function to determine where entries are stored. This implementation handles collisions using **separate chaining** with linked lists.

**Features:**
- Insert key-value pairs
- Retrieve values by key
- Update existing keys
- Remove entries by key
- Check whether a key exists
- Display the contents of the table
- Clear the table

1. Clone or download this repository.

3. Make sure a Java JDK is configured.
4. Open `Main.java`.
5. Run the `main()` method to see the demonstrations.
